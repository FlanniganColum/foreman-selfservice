Foreman Self-Service Portal has been installed.

1. Check workloads:
   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

2. Check the web rollout:
   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "foreman-selfservice.fullname" . }}-web

{{- if .Values.ingress.enabled }}
3. Portal URL:
   https://{{ .Values.ingress.host }}
{{- else }}
3. Port-forward locally:
   kubectl -n {{ .Release.Namespace }} port-forward service/{{ include "foreman-selfservice.fullname" . }} 8080:{{ .Values.web.service.port }}
{{- end }}

4. Run chart test:
   helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

The scheduler is intentionally fixed at one replica. Scale only web and worker.
