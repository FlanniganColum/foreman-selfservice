# Branding assets

These assets were generated specifically for this Foreman Self-Service Portal build.

- `logo-master.png` — full light-theme wordmark used by the portal.
- `brand-mark.png` — square icon derived from the generated master and suitable for launchers/docs.
- `app/static/img/favicon.png` — browser icon.

The web UI uses the full wordmark from `app/static/img/foreman-selfservice-logo.png`.
